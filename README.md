# College Admission Portal (OOPS Project)

A Core Java + HTML/CSS/JavaScript web portal modeled after the **State CET Cell Centralized Admission Process (CAP)** for undergraduate engineering admissions.

## Project Location
The full application source code, data storage, and documentation are located in:
[`CollegeAdmissionPortal/`](file:///c:/Projects/oops%20project/CollegeAdmissionPortal/README.md)

## Admission Workflow
```
Student Registration → Login → Personal Details → Academic Marks →
Document Upload (Aadhaar, SSC, HSC, CET) → Branch Preferences (Priority 1-6) →
Application Submission → Admin Verification → Branch Allocation →
Student Acceptance → Admission Confirmed
```

## Quick Start
Run `CollegeAdmissionPortal/run.bat` or navigate to `CollegeAdmissionPortal/backend` and run:
```cmd
javac *.java
java Main
```
Then open `http://localhost:8080/` in your browser.
